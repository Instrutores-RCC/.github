# Conduta

1. Aqui vale o mesmo Código de Conduta Militar da RCC que vale no fórum e no jogo.
2. Revisão critica o código, nunca a pessoa.
3. Ninguém expõe dado, print ou conversa privada de outro membro.
4. Quem está aprendendo pergunta à vontade; quem sabe responde sem desdém.
5. Problema de conduta vai em particular para a liderança do Departamento de Desenvolvimento ou para a liderança dos Instrutores.
