# Instrutores RCC

Projetos do Departamento de Instrutores da RCC: páginas do fórum, Apps Script e planilhas dos setores.

## Setores

| Sigla | Setor | Projetos |
|---|---|---|
| SRC | Setor de Relações Comunicativas | Central do SRC, Quadro de Advertências |
| SSI | Setor de Segurança dos Instrutores | em breve |
| DA | Departamento de Aplicação | em breve |
| Ouvidoria | Ouvidoria dos Instrutores | Nova Ouvidoria |

## Pedir um projeto

Abra uma issue no repositório do setor com o formulário **Pedido de setor**, ou mande MP no fórum para a liderança do Departamento de Desenvolvimento.
